# المنهج الابتدائي م محسن

مشروع أندرويد أولي يغلّف صفحة HTML داخل WebView.

## بناء APK من GitHub Actions
1. ارفع جميع ملفات هذا المجلد إلى جذر المستودع، مع إظهار الملفات المخفية حتى يشمل مجلد `.github`.
2. افتح تبويب Actions في GitHub.
3. اختر Build Android APK ثم Run workflow.
4. بعد نجاح التشغيل، افتح تفاصيل التشغيل ونزّل artifact باسم `almanhaj-mohsen-debug-apk`.
5. فك ضغط artifact وستجد `app-debug.apk`.

هذا APK تجريبي موقّع بمفتاح debug تلقائياً من Android Gradle Plugin؛ ليس إصداراً نهائياً موقّعاً بمفتاح نشر خاص. احتفظ بمفتاح نشر خاص إذا أردت تحديثات مستقبلية بنفس هوية التوقيع.

محتوى الملخصات في HTML تجريبي ويحتاج مراجعة ومطابقة مع الكتب الرسمية العراقية. لا تستخدم بيانات دخول تجريبية حقيقية أو كلمة مرور شخصية.
